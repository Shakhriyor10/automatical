# Telegram bot

Бот работает локально на этом же проекте и читает ту же базу `db.sqlite3`.
Интернет нужен только для связи с Telegram.

## 1. Создать бота

1. Откройте Telegram.
2. Найдите `@BotFather`.
3. Отправьте `/newbot`.
4. Скопируйте токен.

## 2. Вставить токен

Откройте файл `.env` в корне проекта и замените:

```text
TELEGRAM_BOT_TOKEN=PASTE_YOUR_TELEGRAM_BOT_TOKEN_HERE
```

на ваш токен:

```text
TELEGRAM_BOT_TOKEN=123456789:AA...
```

Если нужно закрыть доступ только для себя, укажите свой Telegram user id:

```text
TELEGRAM_ALLOWED_USER_IDS=123456789
```

Если оставить пустым, бот будет отвечать любому, кто знает username бота.

## 3. Запуск

Самый простой вариант:

```powershell
.\start_bot.bat
```

Или вручную:

```powershell
.\.venv\Scripts\python.exe manage.py run_telegram_bot
```

После запуска бот сам сканирует Wi-Fi в фоне каждые 10 секунд.
Интервал можно изменить в `.env`:

```text
TELEGRAM_SCAN_INTERVAL_SECONDS=10
```

## Команды

- `/start` - открыть меню
- `/today` - журнал за сегодня
- `/present` - кто сейчас на работе
- `/absent` - кого сейчас нет
- `/date 2026-05-21` - отчет за выбранную дату
- `/scan` - вручную запустить Wi-Fi сканирование

В отчетах используются индикаторы:

- `👤` - сотрудник
- `🟢` перед именем - сегодня уже приходил вовремя
- `🟠` перед именем - сегодня приходил, но опоздал
- `🔴` перед именем - сегодня еще не приходил
- `🟢` перед статусом - сейчас на работе
- `🔴` перед статусом - сейчас не на работе

## Предупреждения в группу

Бот может сам писать в группу, если сотрудник не пришел вовремя.
Настройки лежат в `.env`:

```text
TELEGRAM_LATE_ALERT_CHAT_ID=5262110076
TELEGRAM_LATE_ALERT_START_TIME=
TELEGRAM_LATE_ALERT_REPEAT_MINUTES=30
TELEGRAM_LATE_ALERT_CHECK_INTERVAL_SECONDS=30
```

Если `TELEGRAM_LATE_ALERT_START_TIME` пустой, бот использует время из сотрудника:
`Начало работы + Допустимое опоздание`.
Например, начало `09:20` и допустимое опоздание `20` минут означает первое предупреждение в `09:40`.
Следующее предупреждение будет через `TELEGRAM_LATE_ALERT_REPEAT_MINUTES`, например в `10:10`.

Для теста можно поставить текущее время, например:

```text
TELEGRAM_LATE_ALERT_START_TIME=16:52
```

У сотрудника в админке появилось поле `Telegram user`.
Можно указать:

- `username` или `@username` - бот напишет `@username`
- числовой Telegram user id - бот сделает кликабельное упоминание
- пусто - бот напишет имя из базы

Когда сотрудник появится в Wi-Fi, бот изменит последнее предупреждение на сообщение `Сотрудник пришел` с временем прихода.
